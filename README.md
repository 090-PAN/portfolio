# 潘佳丽 · 3D 个人作品集（单文件版）

> 让每一份数据，都被用出价值。

一座漂浮小岛 + 一间工作室，每个物件对应一个模块。整个网站只有一个 `index.html`，Three.js 与图片全部内联，双击就能打开，也能直接托管到 GitHub Pages。

**线上地址**：https://090-pan.github.io/portfolio/
**仓库**：https://github.com/090-PAN/portfolio

## 1. 怎么打开

- **直接双击** `index.html`（Chrome / Edge / Safari 均可）。
- 不需要装依赖：Three.js 已内联，证件照与作品图片都已 base64 内嵌。
- 也可用本地小服务（部分浏览器对本地文件权限更严格）：

```bash
cd 这个文件夹
python3 -m http.server 8000
# 访问 http://localhost:8000
```

| --- | --- | --- |

手机端：面板自动变成底部抽屉，导航栏折成两行，画幅自动适配竖屏，象棋盘按面板宽度自适应。

## 3. 最该改的三件事

打开 `index.html`，搜索 `const CFG = {`，所有个人信息都在这一个对象里，改完保存、刷新即可（不用碰 3D 代码）。

1. **联系方式（已填真实信息）**
   `contact` 里已是真邮箱与电话；小红书账号还没填，有的话补一行就行。
2. **爱好照片**
   `hobbies` 每条用 `photos: []` 放图片地址；象棋和音乐暂时没有照片，会显示一句占位文案（`empty` 字段可改）。
3. **足迹**
   `footprints` 里已有 4 个地点，每条可带 `photos` 数组；`footprintsTodo` 是照片墙下那句提示文案，可删可留。

其余文案（`internships` / `studentWork` / `honors` / `works` / `skills`）都取自原始 PPT，可直接改字句。

## 4. 换作品图片 / 换自己的 3D 小人（可选）

- **换作品封面**：`works` 每条支持 `cover` 字段（值为图片地址或 base64），没有 `cover` 的卡片会自动变成纯文字卡。
- **换 3D 小人**：当前小人是几何体拼的（不占体积、任何浏览器都能跑）。想换成 Meshy 生成的真人形象：Meshy 上传四视图 → 绑 2 个动作（步行 + 互动，别绑太多否则会卡）→ 导出 GLB → 用 GLTFLoader 加载后替换 `const avatar = new THREE.Group()` 那段，位置放在 `(-1.35, 0, 1.5)` 附近。GLB 发我也可以帮你接。

## 5. 更新线上版本

```bash
cd portfolio-repo
# 把新的 index.html 覆盖进来
git add -A && git commit -m "update content" && git push
```

GitHub Pages 约 1 分钟后自动重建，不需要在网页上点任何按钮。

## 6. 性能与兼容

- 单文件约 1.2 MB（含 Three.js、证件照、作品图与 4 张生活照），gzip 传输约 400 KB 左右。
- 需要 WebGL（近 5 年的主流浏览器都支持）。
- 手机端自动降低像素比与画幅；面板打开时 3D 会停止抬升物件，避免抖动。
