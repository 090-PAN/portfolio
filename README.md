# 潘佳丽 · 3D 个人作品集（单文件版）

> 让每一份数据，都被用出价值。

一座漂浮小岛 + 一间工作室，每个物件对应一个模块。整个网站只有一个 `index.html`，Three.js 与图片全部内联，双击就能打开，也能直接托管到 GitHub Pages。

**线上地址**：https://090-pan.github.io/portfolio/
**仓库**：https://github.com/090-PAN/portfolio

## 1. 怎么打开

- **直接双击** `index.html`（Chrome / Edge / Safari 均可）。
- 不需要装依赖：Three.js 已内联，证件照与作品图片都已 base64 内嵌。
- 也可用本地小服务（部分浏览器对本地文件权限更严格）：

```bash
cd 这个文件夹
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 3. 交互（v2 加的细节）

- **入场**：镜头 2.6 秒从高位绕到正面，名字逐字升起。
- **光标**：桌面端是一个跟随的细圆环，移过可点物件或按钮时放大、变蓝。
- **视差**：鼠标移动时镜头轻微横移，像手持拍摄；拖拽时不叠加，避免抖。
- **惯性**：快速拖一下松手，岛会顺着方向继续转一小段再停。
- **点水**：点池塘任意位置会荡开一圈涟漪（点鸭子还是骑鸭）。
- **进模块**：物件脚下会有一圈蓝色光圈扩散；面板右上角显示 `02 / 08` 章节号，标题下有进度条。
- **方向键**：面板关闭时 ← → 转岛，↑ ↓ 俯仰；`1–7` 直达模块。
- **底栏小字**：左下角是本地时间（每 20 秒刷新）与版本号。
- **背景音乐**：一进站就在跑（浏览器不允许无交互出声，所以要你点一下页面才真正响）；右上角 `🔊 音乐` 可以一键静音。
- **歌单**：爱好里的音乐卡不放了自录音，直接跳到网易云官方页——孙燕姿歌手页 / 陶喆歌手页 / 《天黑黑》。
- **骑鸭彩蛋**：现在不是绕圈了——坐上大黄鸭，它会带着你绕岛飞一整圈，经过哪个模块 HUD 就报一站（书架·经历、照片墙·足迹…），`ESC` 下岛。
- **象棋**：红先黑后，两边都能走，不是只有红方能动。
- **信箱留言**：联系方式面板里能写一张纸条投进邮筒。站是纯静态的，没有后端——点「投进信箱」会调用你电脑的邮件客户端把信发到 2292100161@qq.com，不想开邮件就用「复制内容」自己发。投过的草稿存在你自己的浏览器里（localStorage），不会上传。
- **陈设**：草皮加了纹理和割草纹、草丛、睡莲、池边石、门口绿植、屋顶烟囱、侧墙小窗、踏步石、水边长椅、三只蝴蝶。

## 3.7 v2.4：骑鸭按内容定速 + 昼夜 + 五种视觉语汇

- **停留时长按内容算**：每站打开面板后先量一次内容高度，按 40px/秒的阅读速度算停留时间（`1.2s 看开头 + 滚动时长 + 1.8s 收尾`，上限 24 秒）。内容长就多停，一屏放得下就 4.8 秒走。

- **顺序调整**：邮筒改到最后一站（关于 → 经历 → 足迹 → 作品 → 爱好 → 联系），签收完联系方式正好下岛。

- **换 3D 小人**：当前小人是几何体拼的（不占体积、任何浏览器都能跑）。想换成 Meshy 生成的真人形象：Meshy 上传四视图 → 绑 2 个动作（步行 + 互动，别绑太多否则会卡）→ 导出 GLB → 用 GLTFLoader 加载后替换 `const avatar = new THREE.Group()` 那段，位置放在 `(-1.35, 0, 1.5)` 附近。GLB 发我也可以帮你接。


## 8. 性能与兼容

- 单文件约 1.2 MB（含 Three.js、证件照、作品图与 4 张生活照），gzip 传输约 400 KB 左右。
- 需要 WebGL（近 5 年的主流浏览器都支持）。
- 手机端自动降低像素比与画幅；面板打开时 3D 会停止抬升物件，避免抖动。
