# 潘佳丽 · 3D 个人作品集（单文件版）

> 让每一份数据，都被用出价值。

一座漂浮小岛 + 一间工作室，每个物件对应一个模块。整个网站只有一个 `index.html`，Three.js 与图片全部内联，双击就能打开，也能直接托管到 GitHub Pages。

**线上地址**：https://090-pan.github.io/portfolio/
**仓库**：https://github.com/090-PAN/portfolio

## 1. 怎么打开

- **直接双击** `index.html`（Chrome / Edge / Safari 均可）。
- 不需要装依赖：Three.js 已内联，证件照与作品图片都已 base64 内嵌。
- 也可用本地小服务（部分浏览器对本地文件权限更严格）：

```bash
cd 这个文件夹
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 3. 交互（v2 加的细节）

- **入场**：镜头 2.6 秒从高位绕到正面，名字逐字升起。
- **光标**：桌面端是一个跟随的细圆环，移过可点物件或按钮时放大、变蓝。
- **视差**：鼠标移动时镜头轻微横移，像手持拍摄；拖拽时不叠加，避免抖。
- **惯性**：快速拖一下松手，岛会顺着方向继续转一小段再停。
- **点水**：点池塘任意位置会荡开一圈涟漪（点鸭子还是骑鸭）。
- **进模块**：物件脚下会有一圈蓝色光圈扩散；面板右上角显示 `02 / 08` 章节号，标题下有进度条。
- **方向键**：面板关闭时 ← → 转岛，↑ ↓ 俯仰；`1–7` 直达模块。
- **底栏小字**：左下角是本地时间（每 20 秒刷新）与版本号。
- **背景音乐**：一进站就在跑（浏览器不允许无交互出声，所以要你点一下页面才真正响）；右上角 `🔊 音乐` 可以一键静音。
- **歌单**：爱好里的音乐卡不放了自录音，直接跳到网易云官方页——孙燕姿歌手页 / 陶喆歌手页 / 《天黑黑》。
- **骑鸭彩蛋**：现在不是绕圈了——坐上大黄鸭，它会带着你绕岛飞一整圈，经过哪个模块 HUD 就报一站（书架·经历、照片墙·足迹…），`ESC` 下岛。
- **象棋**：红先黑后，两边都能走，不是只有红方能动。
- **信箱留言**：联系方式面板里能写一张纸条投进邮筒。站是纯静态的，没有后端——点「投进信箱」会调用你电脑的邮件客户端把信发到 2292100161@qq.com，不想开邮件就用「复制内容」自己发。投过的草稿存在你自己的浏览器里（localStorage），不会上传。
- **陈设**：草皮加了纹理和割草纹、草丛、睡莲、池边石、门口绿植、屋顶烟囱、侧墙小窗、踏步石、水边长椅、三只蝴蝶。

## 3.5 视觉精修（v2.2）

- **面板更宽**：桌面端 `clamp(430px, 44vw, 660px)`，1440 屏约 633px；正文 13.3px / 行高 1.8，一行约 40 个汉字，读起来不挤也不散。
- **标题换衬线**：面板标题用宋体衬线（Songti SC / Source Han Serif，系统自带，不额外加载字体），正文仍是黑体；章节小标压到 10.5px、字距 2px。
- **底栏图标**：emoji 换成 15px 线性 SVG（房子 / 书 / 显示器 / 马 / 相机 / 信封 / 机器人 / 星芒），选中态白字深底，跨设备显示一致。
- **排版细节**：卡片 18px 圆角、内边距 17/18、统计数字用等宽数字；分隔细线、阴影更轻。
- **可用性**：键盘 Tab 有可见焦点框；系统开启「减少动效」时自动跳过入场飞行、隐藏跟随光标、名字直接显示；面板打开时底栏与左下角信息自动让位，不会被遮住。

## 3.6 v2.3：骑鸭巡站 + 建模重做 + 60% 面板

- **骑鸭变成「一站一站看」**：坐上小鸭，它会飞到工作室 → 书架 → 照片墙 → 邮筒 → 展示板 → 象棋桌，每到一站**自动展开对应面板**，停 6 秒后收起飞去下一站；HUD 显示「第 3 / 6 站 · 展示板 · 作品」，`ESC` 随时下岛。
- **小鸭重做**：从三块球拼的方块鸭，换成平滑椭球身体 + 独立脑袋 + 扁嘴 + 腮红 + 大眼高光 + 贴肩小翅 + 三瓣小皇冠，水面会轻轻上下浮动。
- **工作室重做**：四棱锥屋顶换成双坡瓦屋顶（Canvas 瓦片贴图 + 檐口木条 + 屋脊），加了石砌基座、四角木柱、前后山墙、山墙招牌（不再悬空）、窗台花箱、竖棂窗、砖砌烟囱落在坡面上。
- **右侧面板 60%**：`clamp(520px,60vw,1200px)`；宽屏下作品 / 荣誉 / 实习卡片自动两列等高排列，数据卡四列；象棋盘限宽 620px 居中，不再一屏塞满；面板打开时底栏自动收成图标。
- **简历内容补进小岛**：新增 GPA 3.506/4（专业 12/239）、八门核心课程分数、计算机二级、淘宝购物行为转化漏斗项目、岳麓区志愿者联合会（1000+ 志愿者 / 50+ 场活动）、数智化训练营小组负责人；聚簇云补「采集—清洗—报表」流程沉淀。

## 3.7 v2.4：骑鸭按内容定速 + 昼夜 + 五种视觉语汇

- **停留时长按内容算**：每站打开面板后先量一次内容高度，按 40px/秒的阅读速度算停留时间（`1.2s 看开头 + 滚动时长 + 1.8s 收尾`，上限 24 秒）。内容长就多停，一屏放得下就 4.8 秒走。
- **自动翻页**：等待 1.2 秒后自动匀速下滚，滚到底再走；你一碰面板（点、滚、触）就立刻停手，改成「慢慢看，看完再走」。
- **顺序调整**：邮筒改到最后一站（关于 → 经历 → 足迹 → 作品 → 爱好 → 联系），签收完联系方式正好下岛。
- **昼夜三档**：右上角 ☀ / 🌇 / 🌙 切换白天、黄昏、夜晚；白天到黄昏再到夜晚，太阳色温、环境光、室内灯与串灯亮度、暖光点光、水面反光一起变化，夜晚有星点。夜晚会同时把标题与按钮换成浅色，保证看得清。
- **数字滚动**：关于页的「4 段 / 2 项 / 国赛一等 / 15 项+」打开时从 0 滚到目标值，像数据新闻的计数器。
- **贴纸标签**：作品卡上的技能标签做成白边贴纸，轻微倾斜 + 落影。
- **拼贴照片**：足迹与荣誉的图片改成白边相纸 + 胶带 + 轻微旋转的拼贴效果。
- **弥散渐变**：面板头部加了一层低饱和的极光光斑，白卡片看起来更通透。

## 7. 更新线上版本

```bash
cd portfolio-repo
# 把新的 index.html 覆盖进来
git add -A && git commit -m "update content" && git push
```

GitHub Pages 约 1 分钟后自动重建，不需要在网页上点任何按钮。

## 8. 性能与兼容

- 单文件约 1.2 MB（含 Three.js、证件照、作品图与 4 张生活照），gzip 传输约 400 KB 左右。
- 需要 WebGL（近 5 年的主流浏览器都支持）。
- 手机端自动降低像素比与画幅；面板打开时 3D 会停止抬升物件，避免抖动。
