# 潘佳丽 · 3D 个人作品集（单文件版）

> 让每一份数据，都被用出价值。

一个可以直接双击打开、也可以一键部署的 3D 个人作品集网站：一座漂浮小岛 + 一间工作室，每个物件对应一个模块。

## 1. 怎么打开

- **直接双击** `index.html`（Chrome / Edge / Safari 均可）。
- 不需要装任何依赖：Three.js 已内联进 HTML，证件照也已 base64 内嵌，**整个网站只有这一个文件**。
- 也建议用本地小服务打开（少数浏览器对本地文件权限更严格）：
  ```bash
  cd 这个文件夹
  python3 -m http.server 8000
  # 然后访问 http://localhost:8000
  ```

## 3. 最该改的三件事

打开 `index.html`，搜索 `const CFG = {`，所有个人信息都在这一个对象里，改完保存、刷新即可（不需要懂 3D 代码）。

1. **联系方式（一定要改）**
   `contact` 里现在是 `panjiali@example.com`、`github.com/yourname` 这类**占位示例**，投递前换成真实账号。
2. **足迹**
   `footprints` 里现在是「长沙 / 广州」，按同样格式追加城市即可；`footprintsTodo` 是照片墙下那句提示文案，可删可留。
3. **爱好**
   `hobbies` 里的四个爱好是示例文案，改成你自己的（比如读书、羽毛球、做饭）。

其余文案（`internships` / `studentWork` / `honors` / `works` / `skills`）都取自原始 PPT，可直接改字句。

## 4. 想换成自己的 3D 小人（可选）

当前小岛上的小人是**用几何体拼出来的**（不需要模型文件、不占体积、任何浏览器都能跑）。如果想换成 Meshy 生成的真人形象：

1. 用 Meshy.ai 上传四视图 + 提示词生成模型 → 绑 2 个动作（建议「步行 + 互动」）→ 导出 **GLB**（别绑太多动作，包大了会卡）。
2. 在 `index.html` 里加一个 GLTFLoader（Three.js 示例目录里就有），把 GLB 加载后替换掉 `const avatar = new THREE.Group()` 那段小人代码，位置仍放在 `(-1.35, 0, 1.5)` 附近即可。
3. 或者直接联系我，把 GLB 发过来，我帮你接进去。

## 5. 怎么发布到线上（求职用）

任选一种，都是免费的：

- **GitHub Pages**：新建仓库 → 上传 `index.html` → Settings → Pages → 选 `main` / 根目录 → 得到 `https://用户名.github.io/仓库名/`。
- **Vercel / Netlify**：把文件夹拖进去，自动给你一个域名。
- **国内访问更稳**：腾讯云 / 阿里云 COS + 静态网站托管（需备案），或用 Gitee Pages。

建议再配一个自己的短域名，简历上写「作品集：xxx.com」，比放 GitHub 链接更有辨识度。

## 6. 性能与兼容

- 单文件约 0.74 MB（含 Three.js 与照片），首屏 1 秒内可交互。
- 需要浏览器支持 WebGL（近 5 年的主流浏览器都支持）。
- 手机上会自动降低像素比与画幅，避免发热掉帧。
